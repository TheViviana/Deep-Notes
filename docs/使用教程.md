# Deep Notes 使用教程

Deep Notes（原 Neural Creator Dashboard 修改版）把你的作品、方法笔记、选题和草稿推导成一张会呼吸的神经网络：中心是光球，六只发光水母代表六个模块，点开水母触须伞状展开到每一篇内容，点开一篇右侧弹出完整分析与双向链接。**默认完全断网，所有数据只存在你的设备本地。**

---

## 1. 安装与启动

### 网页版

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务器，默认 http://127.0.0.1:5173/
```

### 桌面版（macOS）

```bash
npm run build              # 先构建静态文件到 dist/
npm run electron:dist:mac  # 打包 macOS 应用，产物在 electron-dist/
```

得到 `.dmg` / `.app`（未签名，首次打开需右键 → 打开）。开发调试用 `npm run electron:dev`（同时起 Vite 和 Electron 壳，支持热更新）。

## 2. 认识工作台

打开页面后是**工作台**：

- 中心**光球**与背景神经网络常亮；**六只水母**分别代表：作品库、概念网络、方法库、选题池、创作台、阅读区。
- **点水母** → 光球退到左侧，触须扇形展开到该模块的每一篇内容；内容超过 15 条时扇形只展开最近的，末尾出现「还有 N 条」折叠条目，点击直达对应页面看全部。
- **点某篇内容** → 右侧滑出分析栏：数据指标、收藏率、出链 / 反链 / 双向共振、话题与二度关联；方法笔记的「阅读全文」默认渲染成排版视图（双链可点击跳转），可切「查看原文」看 Markdown 符号。
- 按 `Esc` 或点面包屑逐层返回。
- 底部**问答条**：用本地规则问你的图谱，例如「最核心的内容」「双向连接有哪些」「下一篇写什么」「未创建的笔记」——不联网、不调用 AI。

## 3. 把自己的笔记放进来

### 方式一：软件内导入（推荐）

点右上角头像 → **「关于这份数据」** → **「导入知识库文件夹」**，先选导入去向，再选你的 Markdown / Obsidian 文件夹即可：

- **按文件夹自动分类**：与命令行同规则，按文件夹名识别（作品 / 草稿 / 选题 / 方法 / 阅读），识别不了的一律作为方法笔记；
- **全部到作品库 / 方法库 / 选题池 / 创作台 / 阅读区**：文件夹里所有 Markdown 统一归入所选模块，不用改文件夹名。

**桌面版会为导入的知识库新建文件夹副本**：在你所选文件夹旁边生成「`<原名> - Deep Notes`」（重名自动加序号），之后在软件里的新建、编辑、删除都会实时写回这个副本里的 `.md` 文件（删除的内容移入副本的 `.trash`），**你原来的文件夹内容保持不动**。副本就是你的知识库，可以继续用 Obsidian 等编辑器打开它。「关于这份数据」弹窗里会显示当前副本的完整路径；「切回示例数据」会停用写回，但盘上的副本原样保留。网页版没有文件读写能力，导入结果只保存在浏览器里。

随时可**「切回示例数据」**。

### 方式二：命令行导入

```bash
npm run import -- --vault "<你的笔记文件夹>" --account "<账号名>" --followers 1280
npm run import -- --reset    # 切回示例数据
npm run import -- --help     # 查看全部选项
```

- 按文件夹名自动识别：含「作品 / works」→ 作品，「方法 / 模板 / 流程 / methods」→ 方法笔记，「选题 / ideas」→ 选题，「草稿 / 创作台 / drafts」→ 草稿；识别不准可用 `--works` `--methods` `--ideas` `--drafts` 手动指定。
- 作品数据写在 frontmatter 里，中英文字段都认：`观看/views`、`点赞/likes`、`评论/comments`、`收藏/saves`、`涨粉/follows`、`分享/shares`、`曝光/impressions`、`封面点击率/ctr`、`平均观看时长/duration`、`发布时间/date`、`类型/media`（视频 / 图文）、`tags`。支持「1.2万」「12.4%」「21s」这类写法。
- 正文里的 `[[双链]]` 自动连线；同一话题标签出现在两条以上内容里会生成「概念」节点。
- 导入结果写入 `src/data/my-data.js`（已 gitignore，不会被提交）。

### 图谱的连接规则

| 连接 | 规则 |
|---|---|
| 目录归属 | 内容属于哪个模块 / 子目录 |
| `[[双链]]` | 笔记与草稿正文里的双链；未创建的显示为「未创建」幽灵节点 |
| 选题来源 | 草稿记录来源选题，选题「已转草稿」时反向也成立 |
| 话题标签 | 作品的话题 |
| 正文提及 | 正文出现概念词，至少两条内容提及才成为概念节点 |
| 双向共振 | 两条内容共同提及 ≥ 2 个概念 |

## 4. 六个内页

- **作品库**：作品卡片、排序；数据指标（浏览 / 点赞 / 曝光等）与媒体类型可手动修正；分析栏里可编辑双向链接（新增带自动补全，不存在的目标可一键创建；反链会引导你回源笔记修改，避免不一致）。
- **方法库**：左侧笔记列表按**二级分类**分组（默认沿用导入时的子目录），右侧就地编辑——标题重命名自动同步路径文件名，正文支持 `[[` 双链补全与格式工具栏，「阅读」可切渲染视图，「专注」隐藏左列表让编辑区占满，「移动到」可把笔记移去其他模块；首页方法笔记的分析栏也有「打开编辑器」直达。
- **分类整理（方法库）**：笔记可直接**拖拽**到其他分类（分组头会高亮），也可以拖到顶栏的模块名上跨模块移动；列表底部「＋新建分类」可加空分类，悬停分组头会出现**重命名**与**删除**按钮（删除非空分类时，里面的笔记自动移入「未分类」）；编辑区左上角的分类下拉选择即移动。以上操作都是原地完成，不刷新页面，选中的笔记和编辑内容保持不动。
- **创作台**：见下一节，功能最多的页面。
- **选题池**：编辑平台 / 优先级 / 状态 / 备注，删除选题，一键**转草稿**；转草稿后草稿会带着选题标题与备注进入创作台，选题自动移出选题池（草稿仍记录来源，可随时从分析栏回看）。桌面版连接知识库时选题会写进副本的「04-选题池」文件夹（frontmatter 带全部字段），清缓存、换设备都不丢。
- **阅读区**：放别人写好的内容，自己拿来阅读——「添加阅读」新建条目（标题、作者、来源、日期、正文），点开即进入文章全文视图，可切「预览」阅读排版结果（支持沉浸式翻译），也可留在编辑模式做**批注**；正文里的 `[[双链]]` 照常汇入图谱，双链目标可以是自己的文章、笔记或草稿。
- **分类整理（阅读区）**：左侧是**分类目录**——「＋新建分类」加空分类，悬停分类出现**重命名**与**删除**按钮（删除非空分类时，里面的阅读自动移入「未分类」）；阅读卡片可**拖拽**到左侧分类上归类，也可拖到顶栏模块名上跨模块移动；点分类名可筛选该分类，点「全部阅读」看全部。全程原地完成，不刷新页面。
- **档案区**：放**你自己**的个人档案——个人简介、年度回顾、技能与工具清单、创作原则等。「新建档案」后直接写正文，`[[双链]]` 照常汇入图谱；标题、日期可改，可删除，也能从分析栏移动到其他模块。档案区在首页有自己的水母与主题色。
- **跨模块移动**：文章 / 笔记 / 草稿 / 选题 / 阅读 / 档案 六类内容互通——首页分析栏点「移动到…」，或在方法库 / 创作台的编辑器工具条点「移动到」，选目标模块即可，标题和正文一起带走，随时可以再移回来。
- 另外一处可编辑内容：**概念网络**支持概念改名、关键词增删与删除概念（首页概念水母 → 点概念 → 分析栏）。

所有修改实时保存到浏览器 `localStorage`（桌面版存 Electron 用户数据目录），图谱连接、字数、幽灵节点数量即时更新；存储空间紧张时自动降级——先暂停全量快照保住正文，未落盘的修改留底 IndexedDB 不因存储满丢失；保存失败会弹顶栏通知条提醒（不会静默丢失），程序级异常由兜底页接管、可一键重载。

## 5. 创作台：编辑器全功能

### 编辑基础

- `[[` 触发**双链补全**；未创建的双链可一键**创建为文章 / 方法笔记**。
- 输入 `/` 触发**斜杠命令**菜单（插入标题、列表、引用、双链等）。
- 选中文本弹出**格式工具栏**（加粗、斜体、代码、链接…），也可用模板菜单直接插入片段。
- **模板库**：内置常用结构模板，支持在插件管理中添加**自定义模板**。
- 编辑器元信息行实时显示字数、双链数与插件徽标（阅读时长等）。

### 编辑器视图（可自由叠加）

| 视图 | 作用 |
|---|---|
| **专注** | 隐藏左右两侧卡片，编辑区占满整行 |
| **阅读** | 当前草稿渲染成排版视图，`[[双链]]` 可点击跳转 |
| **对照** | 左侧固定只读面板，从下拉选择另一篇文章 / 草稿 / 笔记并排阅读 |
| **移动到** | 把这篇草稿移到其他模块（作品库 / 方法库 / 选题池），标题正文一起带走 |

- **对照分屏中间的分割线可以拖动**调整左右宽度（25%–75%），**双击恢复对半**，Tab 聚焦后按 `←` / `→` 每次微调 2%；位置会记住，刷新后保持。
- 专注 + 对照可叠加：两侧卡片隐藏后中间照常分屏，适合一边写一边参考。

### 大纲目录（TOC）

平时收进编辑区右缘的一条**竖线**（带标题数角标），鼠标移上去自动滑出大纲，点击标题跳到对应位置；移开后自动收回。**阅读模式与「阅读全文」弹窗里同样可用**：竖线悬停在渲染视图右缘，点击标题滚动到对应章节，滚动时高亮当前位置。

### 文字颜色与高亮

- 工具栏的 **A**（带彩色下划线）弹出调色板：选中文字后点色块即可上色（红 / 橙 / 黄 / 绿 / 蓝 / 紫 / 粉），选「默认」清除颜色。颜色以 `<span style="color:…">` 形式保存在正文里，编辑视图（当前行之外的行）、阅读视图、对照面板、「阅读全文」中都会显示。
- 工具栏的 **彩**（高亮）用 `==高亮文字==` 语法包裹选区，渲染为金色荧光底。

## 6. 插件系统

顶栏头像旁 / 「关于这份数据」里可管理插件。当前内置：

| 插件 | 说明 | 联网 |
|---|---|---|
| 斜杠命令 | `/` 呼出插入菜单 | 否 |
| 打字机模式 | 当前行居中，其余淡出 | 否 |
| 双链体检 | 扫出断链与未创建双链 | 否 |
| 阅读时长 | 估算并显示预计阅读时间 | 否 |
| 格式工具栏 | 选中文本快捷格式化，含七色文字颜色与高亮 | 否 |
| 大纲目录 | 右缘竖线悬停弹出，阅读模式同样可用 | 否 |
| 模板库 | 内置 + 自定义模板插入 | 否 |
| 沉浸式翻译 | 生成双语对照阅读 | **需要联网开关** |
| AI 助手 | 接入自配 API 的对话与文件读写 | **需要联网开关** |

### 沉浸式翻译

打开**顶栏联网开关** + 启用插件后，阅读视图自动生成中英对照；关闭任一开关即恢复纯本地。

### AI 助手

使用前提（三者缺一不可）：

1. **顶栏联网开关**打开；
2. **插件管理**里启用「AI 助手」；
3. 配置一个 **OpenAI 兼容 API** 的 key（点对话坞输入框旁的 AI 服务商芯片，选择 DeepSeek / OpenAI / OpenRouter / 硅基流动 / Ollama 本地 / 自定义，填入 Base URL、API key、模型，并选择推理等级：关 / 低 / 高 / 最大——DeepSeek 可选 DeepSeek V4.1 Flash（`deepseek-v4-flash`）与 DeepSeek V4 Pro（`deepseek-v4-pro`）两款模型，推理等级经 `reasoning_effort` 传给 API（「关」不传此字段），模型清单与 DeepSeek Harness 一致；旧配置里保存的 `deepseek-chat` / `deepseek-reasoner` 已退役会自动归一，「标准 / 深度思考」两档旧设置分别迁移为「关 / 高」）。

**key 加密后只存本机 localStorage，不上传**（桌面版经系统 safeStorage 加密，密文一次性落盘，不产生中间态）。启用后：

- **工作台**：底部对话框坞直接变成 AI 对话；
- **其他界面**：右下角浮动按钮唤起对话面板，与工作台共用同一条会话；
- AI 能**感知当前界面内容**（你在看哪篇、编辑器里是什么），并可通过对话直接对文章 / 草稿 / 笔记**增删改查**（删除前会弹窗确认，AI 提出改写标题 / 正文时也会先弹窗展示改动内容、确认后才执行）。

> 断网默认：关闭联网开关或插件开关，AI 助手立即回到不可用状态，不发任何请求。

## 7. 数据与隐私

- **默认完全断网**：不加载任何统计脚本，不调用任何云服务。仅有的联网出口是上面两个插件，且都必须手动打开联网开关。
- 选题、草稿、目标、作品编辑等保存在 `localStorage`；键名前缀在 `src/config.js` 的 `storagePrefix`。**改前缀等于切换到一套全新数据**（旧的还在，改回来就恢复）。桌面版**连接知识库后**，文章 / 笔记 / 草稿 / 阅读 / 档案 / 选题改为只以盘上 `.md` 为准（启动直接读盘，localStorage 不再保存这些内容），闪念箱、概念定义、概念 / 段落闪卡另存库根隐藏文件 `.deepnotes/meta.json`，随知识库文件夹一起搬走；本机 localStorage 仍保留一份作为兜底。
- **桌面版文件夹知识库**：导入时所选文件夹旁会新建「`<原名> - Deep Notes`」副本，作品 / 方法笔记 / 草稿 / 阅读 / 选题的增删改实时写回副本里的 `.md` 文件（带 frontmatter，字段与导入格式一致；删除的内容进 `.trash`），原文件夹不动；知识库路径记录在 localStorage 的 `-vault-root-v1` 键。知识库根目录需经系统对话框授权（导入时亲自选过的文件夹自动登记并永久记住；升级老用户已连接的库首次访问会弹一次确认框，拒绝的选择也会被记住、不会每次启动重复追问；导入生成的「- Deep Notes」副本首次访问同样会确认一次），应用只在授权过的目录内读写。应用会**监听副本文件夹**——在 Obsidian 等外部编辑器里的改动约 2 秒后自动同步进应用；iCloud 尚未下载的占位文件会被跳过，不会误当作已删除。若某次写盘最终失败（如磁盘满、文件被占用），这条修改会**留底待重试**并在下次启动时顶栏横幅提示，此时自动同步先暂停，点「重试写盘」恢复、点「放弃」丢弃（避免半新半旧互相覆盖）；之后任何一次写盘成功也会自动补写留底的内容，留底不会被静默清掉。网页版没有此能力，一切只存浏览器。
- **本地视频**：正文里写 `![[课程.mp4|480]]` 或 `![](课程.mp4)` 会直接出现播放器；表格里的 `[文件名](x.mp4)` 点击后弹出灯箱播放，可拖动进度、Esc 关闭。视频只在桌面版可播放（网页版显示占位提示）。视频**不复制**进「- Deep Notes」副本，播放时直接从副本读取、找不到再回退到旁边同名的原始库只读读取——课程视频再大也不会让 iCloud 副本体积翻倍。导出 PDF 时视频位置会换成文字引用说明，不会出现黑框。
- 「关于这份数据」弹窗可查看数据来源与统计口径（桌面版还显示当前知识库文件夹路径），也可在这里重置。
- 个人笔记文件 `src/data/my-data.js` 已在 `.gitignore`，不会被提交或打包公开。

## 8. 常见问题

**首页光球 / 水母不见了？** 刷新页面；若仍不见，运行 `npm run verify` 检查核心动效素材是否在位（`public/media/orb.mp4`、`jellyfish.mp4`）。

**换了数据但页面还显示旧的选题 / 草稿？** 数据存在 localStorage。改 `src/config.js` 的 `storagePrefix`，或清空该站点的 localStorage。

**正文里的视频不播放？** 视频只在桌面版可播放（网页版只有占位框）；确认视频文件就在知识库或旁边同名的原始库里、且该文件夹已授权。如果原文件在 iCloud 上尚未下载，先在 Finder 里点一下下载，再重新打开这一篇。

**桌面版打不开？** 分两种提示：

- 「**无法验证开发者**」：右键点 .app → 打开；或到「系统设置 → 隐私与安全性」里点「仍要打开」。
- 「**"Deep Notes"已损坏，无法打开，你应该将它移到废纸篓**」：这是 macOS 对未公证应用 + 下载隔离属性的拦截，**不要删**。打开「终端」，执行：

  ```bash
  xattr -cr "/Applications/Deep Notes.app"
  ```

  然后就能正常打开。应用完全本地运行、源码开源，可放心使用。

**AI 对话报「未配置 API key」？** 按「AI 助手」一节配置服务商与 key；确认联网开关与插件开关都已打开。

**导入没识别出作品？** 检查文件夹名是否含「作品 / works」，或用 `--works` 显式指定；frontmatter 字段参考 `examples/vault/` 里的虚构示例。
